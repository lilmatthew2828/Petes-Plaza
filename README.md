# Petes-Plaza
Instructions For Running
Explorer Structure:
petes-plaza/
├── index.html
├── style.css
├── script.js     
└── assets/
    └── IMG_0269 (1).png

How To Run:
Option #1: Using Live Server (Recommended Option)
Have the petes-plaza folder open in the Explorer in VS Code
Install the Liver Server Extension by Ritwick Dey
After the extension has been installed successfully, right-click on the index.html file and select “Open with Live Server”.
Option #2: Direct Browser Open 
Open the petes-plaza folder in the Explorer in VS Code
Double-click on index.html 
Open in any web browser of your choice.
